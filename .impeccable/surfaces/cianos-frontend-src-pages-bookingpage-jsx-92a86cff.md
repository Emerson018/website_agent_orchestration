# Marcianos booking widget

Mode: Operate (a guest reserves a table in under a minute). Self-contained widget, embeddable later in a Marcianos landing page: no photos, prices or sales copy. Reservations confirm instantly; groups of 6+ become a pre-reservation the owner confirms. Capacity per slot counts people.

## Direction contract
THESIS: booking a table is boarding the Marcianos ship; refuse the generic indigo SaaS form with glow blobs and a "Garanta seu Horário" hero.
OWN-WORLD: night-sky ink ground (#07091A family), the logo's three neons as jobs: cyan = action, alien green = selected, orange = the one warm highlight; solid text colours, neon never on body text, glow only on the selected chip and the boarding pass edge; rounded console keys, a dotted flight-path rule linking steps.
STORY: guest sees the ship logo, picks people, day, time, leaves name and WhatsApp, gets a boarding pass with everything needed to arrive.
FIRST VIEWPORT: logo mark and "Reserve sua mesa" top; step 1 people keys immediately below; sticky bottom summary bar with the confirm action in thumb reach.
FORM: user-pinned direction (spacey, from the logo); the concept roll was not run because the user pinned both worlds; seed: none (roll skipped)
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
